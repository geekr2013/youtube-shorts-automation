# 하나 필라테스 Shorts Automation

반응이 없었던 지식·다큐 형식을 중단하고, **동일한 가상 성인 여성 강사 ‘하나’가 초급 필라테스 세 동작을 안내하는 쇼츠**를 매일 한 편 자동 제작·공개합니다.

## 현재 형식

- 강사: 25세로 설정한 성인 동양인 여성 캐릭터 `하나 / HANA`
- 동일 인물 유지: 매번 사람을 새로 만들지 않고 저장소의 검수된 기준 얼굴과 자세 이미지만 사용
- 영상: 9:16 세로형, 전신·측면·정면 구도와 느린 줌을 번갈아 편집
- 내용: 맨몸 매트 동작 중심이며 필라테스 링 동작도 순환 포함
- 구성: 짧은 도입 → 서로 다른 세 동작 → 저장 유도 마무리
- 자막: 동작명·자세 포인트·횟수를 한글과 영어로 함께 표시
- 숫자 음성: `5회`를 기계적으로 읽지 않고 `다섯 번`, `스무 초`처럼 한글 발음용 문장으로 제작
- 음성: 젊은 한국인 여성 필라테스 강사 톤의 Gemini 음성, 장애 시 한국어 여성 신경망 음성으로 전환
- 음악: 기존 불쾌한 전자음을 재사용하지 않으며 배경음악 없음
- 공개: 사실적으로 보이는 가상 인물이므로 YouTube의 합성 콘텐츠 표시를 항상 적용

## 지속 운영 방식

- 검수된 동작 7개와 루틴 10개를 우선 운영
- 최근 5개 루틴과 겹치지 않게 자동 선택
- 아침 코어, 골반 안정, 층간소음 없는 홈트, 저녁 코어, 링 루틴 등으로 순환
- 기존 영상 성과 기록은 보존하지만 지식 영상은 더 이상 생성하지 않음
- 자세 이미지와 루틴을 추가하면 같은 강사 체계로 장기 확장 가능

## 안전 기준

- 치료·완치·통증 제거·감량 보장 등 의료 또는 과장 표현 금지
- 모든 영상에 통증·어지러움·불편함 발생 시 중단 안내
- 부상, 질환, 임신 등 개인 상황은 의료진 또는 자격을 갖춘 지도자 상담 안내
- 하루마다 무검수 AI 자세를 생성하지 않아 얼굴 변화와 관절 오류 위험을 줄임
- 자세 이미지가 없거나 손상되면 업로드 중단
- 한 영상에 서로 다른 세 동작만 사용

## 운영 시간

- 매일 한국 시간 오후 7시 35분
- GitHub Actions에서 실행되므로 PC가 꺼져 있어도 동작
- 코드가 바뀌면 먼저 업로드 없는 실제 영상 제작 검증 실행
- 예약 실행 또는 승인된 수동 실행에서만 YouTube 공개

## 사용 중인 GitHub Secrets

| 이름 | 용도 |
| --- | --- |
| `GEMINI_API_KEY` | 자연스러운 한국어 여성 안내 음성 |
| `GOOGLE_API_KEY` | Gemini 음성 예비 키 |
| `YOUTUBE_DATA_API_KEY` | 기존 영상 성과 갱신, 없어도 영상 제작 가능 |
| `YOUTUBE_CLIENT_ID` | YouTube OAuth 인증 |
| `YOUTUBE_CLIENT_SECRET` | YouTube OAuth 인증 |
| `YOUTUBE_REFRESH_TOKEN` | 자동 업로드 권한 갱신 |
| `SENDER_EMAIL` | 선택 사항: 알림 발신 주소 |
| `GMAIL_PASSWORD` | 선택 사항: Gmail 앱 비밀번호 |
| `RECEIVER_EMAIL` | 선택 사항: 알림 수신 주소 |

Pexels와 Pixabay 키는 새 필라테스 영상에서 사용하지 않습니다.

## 수동 점검

GitHub 저장소의 **Actions → Daily Hana Pilates Short → Run workflow**에서 실행합니다.

- `dry_run = true`: 영상만 만들고 업로드하지 않음
- `dry_run = false`: 실제 공개 업로드

검증 결과의 `short-preview-...` 파일은 3일간 보관됩니다.

## 한계

- 현재 무료 MVP는 생성형 동영상이 아니라 검수된 자세 이미지에 줌·전환·음성·자막을 적용한 영상입니다.
- 실제 움직임을 연속 시연하는 고품질 AI 동영상은 얼굴 및 자세 일관성 검수와 유료 생성 비용이 필요합니다.
- 운동 콘텐츠로 바꾼다고 조회수나 수익화가 보장되지는 않습니다. 초기 10편의 시청 선택률·지속시간·저장·댓글 반응으로 판단해야 합니다.
