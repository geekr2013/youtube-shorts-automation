# HANA Pilates Real-Video Shorts Automation

Pexels·Pixabay에서 사용이 허용된 실제 사람의 운동 동영상을 받아, 필라테스 세 동작 쇼츠로 재편집해 매일 자동 공개합니다. 유료 영상 생성 서비스는 사용하지 않습니다.

## 현재 형식

- 영상: 정지 이미지가 아닌 실제 연속 동작 MP4 세 개만 사용
- 구도: 각 동작을 전신 구도로 시작한 뒤 복부·둔근·내전근·가슴 등 목표 부위를 확대
- 품질 검사: 4~90초, 짧은 변 720px 이상, 20fps 이상, 연속 프레임을 먼저 확인하고 초·중·후반 세 프레임을 Gemini가 다시 검수
- 검수 기준: 지정 동작 일치, 실제 촬영 같은 피부·빛·해부학, 관절과 목표 부위 노출, 전문 운동복, 비성적 교육 구도
- 인물: 실제 성인 운동 영상이며 출연자는 소스에 따라 달라질 수 있음
- 의상 목표: 자세와 관절선을 가리지 않는 전문적인 밀착 운동복과 정돈된 운동 공간
- 피부·빛: 피부 질감을 지우지 않고 명암·채도 편차와 과한 하이라이트만 약하게 보정
- 구성: 첫 프레임부터 동작 → 전신 → 근육 클로즈업 → 세 동작 → 저장 유도 마무리
- 자막: 상단 안전 영역의 반투명 패널에 동작명·자세 포인트·횟수를 한글과 영어로 표시
- 음성: 젊은 한국인 여성 필라테스 강사 톤의 Gemini 음성, 장애 시 무료 한국어 여성 신경망 음성
- 음악: 운동 설명을 방해하지 않도록 배경음악 없음
- 출처: 영상 설명에 제공처·제작자·원본 페이지를 표시

## 인기 쇼츠 분석

- 매일 YouTube Data API로 최근 180일 필라테스 쇼츠를 한 번 검색
- 60초 이하 영상의 조회 속도, 좋아요, 댓글 신호를 계산
- `첫 프레임 동작`, `한 부위에 집중`, `짧은 번호형 루틴`, `저장 유도`, `루프형 마무리`만 편집 규칙으로 사용
- 다른 채널의 영상·인물·문구·음원은 복제하지 않음
- 감량 보장, 며칠 만에 체형 변화 등 과장 효능 문구는 반영하지 않음

## 자동 운영

- 매일 한국 시간 오후 7시 35분 GitHub Actions 실행
- PC가 꺼져 있어도 실제 영상 검색·검사·편집·공개 업로드 진행
- 최근 5편과 겹치지 않게 무료 실제 영상을 안정적으로 찾을 수 있는 4개 루틴을 우선 순환
- 첫 루틴이 검수를 통과하지 못하면 하루 최대 세 루틴까지 대체 영상을 탐색
- 코드 변경 시에는 공개 업로드 없이 미리보기부터 생성
- 실제 영상 세 개 중 하나라도 동작·현실감·가독성 검사를 통과하지 못하거나 Gemini 검수가 중단되면 업로드 중단

## 안전·권리 기준

- Pexels 또는 Pixabay API의 사용 허용 영상만 수집
- 영상 원본을 그대로 올리지 않고 교육용 내레이션, 한·영 자막, 전신·클로즈업 재구성, 안전 안내를 추가
- 치료·완치·통증 제거·감량 보장 등 의료 또는 과장 표현 금지
- 통증·어지러움·불편함이 있으면 즉시 중단하도록 안내
- 부상, 질환, 임신 등 개인 상황은 의료진 또는 자격을 갖춘 지도자 상담 안내
- 실제 영상과 설명 동작이 직접 연결되지 않으면 업로드하지 않음

## 수동 검증

GitHub 저장소의 **Actions → Daily Hana Pilates Short → Run workflow**에서 실행합니다.

- `dry_run = true`: 실제 영상으로 미리보기만 제작
- `dry_run = false`: 검증한 설정으로 YouTube 공개 업로드

결과 파일 `short-preview-...`에는 최종 MP4, 메타데이터, 3×3 확인용 화면표가 포함되며 3일간 보관됩니다.

## 한계

- 무료 스톡 영상만으로 같은 출연자를 장기간 고정할 수는 없습니다.
- 세 프레임 AI 검수는 오동작·부자연스러운 화면을 크게 줄이지만 전체 움직임의 운동학적 정확성을 자격 있는 지도자처럼 보증하지는 못합니다. 첫 배포는 화면표와 영상을 육안 검증한 뒤 공개합니다.
- 제3자 영상에 충분한 교육적 해설과 편집을 추가해도 YouTube의 재사용 콘텐츠 심사는 보장되지 않습니다.
- 조회수·구독·수익은 보장할 수 없으며 초기 10편의 시청 선택률·평균 시청률·저장·댓글 반응으로 판단합니다.
